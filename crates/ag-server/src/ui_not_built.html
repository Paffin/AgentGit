The Web UI is not built into this server

This ag-server is running, and its API works (/v1/…, /healthz, /metrics). What is missing is the browser interface: this binary was built without a build of the UI, and no UI directory is configured.

Pick one:

  1. Build the UI into the binary (needs Node 22), then rebuild the server: 
    scripts/build_ui.sh
cargo build --release -p agentgit-server
  2. Build apps/web (npm ci && npm run build) and point the server at the result, in the server configuration: 
    [ui]
dir = "/path/to/apps/web/dist"
  3. Run without a UI and silence this page: 
    [ui]
enabled = false

Everything else about the server is unaffected. See docs/guides/web-ui.md in the repository.
