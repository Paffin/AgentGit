# dev/

Maintainer working notes for the multi-agent build-out of AgentGit — not user documentation.

* `STATUS.md` — where the project stands, what is in flight, what is next. **Start here.**
* `agent-brief.md` — the shared rules every working agent follows.
* `tracks/tracks.md` — the briefs of the parallel tracks (relaunch prompts).
* `handoff/` — one file per track, written by its agent: state, evidence, next steps.
* `audit/` — the "no mocks / stubs / hardcodes" audit (raw candidate findings; see `STATUS.md`).
* `workflows/` — the audit workflow script.
