# Exceptions to scripts/check_no_stubs.py. One per line:   glob | rule | needle | reason
#
#   glob    a path pattern (fnmatch: `*` also crosses `/`), relative to the repository root
#   rule    todo-macro | marker | for-now | not-implemented | placeholder | stub | test-double
#   needle  text that must occur in the offending line, or `*` for every line of that rule in those files
#   reason  mandatory: why this use is legitimate. If you cannot write one, finish the code instead.
#
# The list is for words that mean something else in context (an HTML input's placeholder, a SQL parameter
# placeholder) and for code whose job is exactly what the word says and is honest about it. It is not a place to
# park unfinished work. An entry that matches nothing is reported (python3 scripts/check_no_stubs.py --strict fails
# on it), so delete entries together with the code they excuse.
